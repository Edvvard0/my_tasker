# Локальный просмотр приложения

Три способа посмотреть экраны, от простого к полному.

## 1. Скриншоты из тестов (ничего не нужно ставить)

Golden-тесты рендерят экраны в размерах телефона и ПК. Эталоны лежат в `app/test/goldens/files/*.png` — их можно открыть прямо на GitHub. После каждого этапа оркестратор присылает новые скриншоты в чат.

## 2. Запуск на ПК через локальный Claude Code (Windows)

Скопируйте промт ниже в Claude Code, открытый в папке репозитория на вашем ПК.

````text
Собери и запусти Flutter-приложение My Tasker из этого репозитория на Windows, чтобы я посмотрел экраны. Ничего в коде не меняй и ничего не коммить.

1. Обнови репозиторий: git fetch && git checkout docs/initial-planning-xb9n7b && git pull.
2. Проверь окружение и при необходимости помоги установить, объясняя каждый шаг:
   - Flutter 3.47.5 (stable) в PATH — `flutter --version`;
   - Visual Studio 2022 (Community подходит) с нагрузкой «Разработка классических приложений на C++», включая компонент ATL (нужен плагину flutter_secure_storage_windows);
   - `flutter doctor` должен показать зелёным пункт Windows.
3. В папке app/ выполни:
   flutter config --enable-windows-desktop
   flutter pub get
   dart run build_runner build --delete-conflicting-outputs
   flutter run -d windows
   Первая сборка скачивает SQLCipher и занимает несколько минут.
4. Если сборка падает — покажи мне ошибку и предложи исправление окружения. Код приложения не правь: ошибки в коде я передам в облачную сессию.
5. Когда окно откроется, подскажи: горячая перезагрузка — клавиша r в терминале, выход — q.
````

Что увидите: десктопную раскладку (боковая панель). Минимальный размер окна — 960×600, поэтому телефонной раскладки на ПК не будет — для неё способ 3.

Сервер для просмотра не нужен: приложение работает офлайн, экран «Настройки → Сервер» просто покажет, что сервер не настроен.

## 3. Запуск на телефоне (Galaxy A55 по USB)

Нужны Android Studio (Android SDK) и режим разработчика на телефоне с «Отладкой по USB». Промт для локального Claude Code:

````text
Запусти Flutter-приложение My Tasker из этого репозитория на моём Android-телефоне, подключённом по USB. Ничего в коде не меняй и не коммить.
1. git fetch && git checkout docs/initial-planning-xb9n7b && git pull.
2. Проверь Flutter 3.47.5, Android SDK (flutter doctor --android-licenses при необходимости) и что `flutter devices` видит телефон; если нет — объясни, как включить отладку по USB на Samsung.
3. В app/: flutter pub get; dart run build_runner build --delete-conflicting-outputs; flutter run -d <id телефона>.
4. Ошибки сборки покажи мне и предложи исправление окружения, код не правь.
````
